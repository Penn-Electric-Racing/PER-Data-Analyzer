# PER-Data-Analyzer

PER's in-house library for log parsing and data analysis.


## Documentation

[https://penn-electric-racing.github.io/PER-Data-Analyzer/](https://penn-electric-racing.github.io/PER-Data-Analyzer/)

Docs are autogenerated using Sphinx. To generate the docs locally, run the following

```bash
cd docs
sphinx-build -b html source build
```

The same build writes `docs/build_index/` (`docs_index.json` + `docs_index.faiss`), a semantic search index over every docstring used by the car-data-server MCP server. CI publishes it to the [`docs-index` release](https://github.com/Penn-Electric-Racing/PER-Data-Analyzer/releases/tag/docs-index) on every push to `main`. The extension lives in `docs/source/_ext/docs_index.py`.

## Testing

We use `pytest` for testing. In the root directory, run the following

```bash
pytest

# Generates coverage report in htmlcov/index.html
pytest --cov=perda --cov-report=html
```
