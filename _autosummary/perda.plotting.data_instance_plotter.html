perda.plotting.data_instance_plotter#

perda.plotting.data_instance_plotter.plot_time_series(rows, timestamp_unit, right_rows=None, title=None, y_axis_titles=None, right_y_axis_titles=None, show_legend=True, vlines=None, max_points=None, log_x=False, log_y=False, width=1200, height=None, vertical_spacing=0.12)[source]#

Plot DataInstances against time as vertically stacked subplots sharing one time axis.

Each subplot has a left y-axis and, optionally, an independent right y-axis for signals with different units or scales. A single row gives an ordinary one-panel plot. Zooming the time axis zooms every subplot together.

Parameters:

  • rows (list[list[DataInstance]]) – Outer list is the subplots, top to bottom. Inner list is the signals drawn against that subplot’s left y-axis (solid lines). An inner list may be empty if that subplot only uses its right axis.

  • timestamp_unit (Timescale) – Unit of the raw timestamps in the DataInstances. They are converted to seconds for the x-axis. Pass aly.data.timestamp_unit.

  • right_rows (list[list[DataInstance]] | None, optional) – Signals drawn against each subplot’s right y-axis (dashed lines), one inner list per subplot in the same order as rows. An empty inner list means that subplot has no right axis. Default is None (no right axes anywhere).

  • title (str | None, optional) – Title shown above the whole figure. Default is None (no title).

  • y_axis_titles (list[str | None] | None, optional) – Left y-axis label for each subplot, e.g. ["Speed (mph)", None]. None entries leave that axis unlabeled. Default is None (no labels).

  • right_y_axis_titles (list[str | None] | None, optional) – Right y-axis label for each subplot. Ignored for subplots without right-axis signals. Default is None (no labels).

  • show_legend (bool, optional) – Whether to show the legend listing each signal. Default is True.

  • vlines (list[float] | None, optional) – Times in seconds at which to draw dashed vertical marker lines on every subplot. Default is None (no lines).

  • max_points (int | None, optional) – Maximum number of points drawn per signal. Longer signals are evenly downsampled (every Nth point), which speeds up rendering of large logs. Default is None (draw every point).

  • log_x (bool, optional) – Use a logarithmic time (x) axis. Default is False (linear).

  • log_y (bool, optional) – Use logarithmic scaling on every y-axis, left and right. Default is False (linear).

  • width (int, optional) – Figure width in pixels. Default is PLOT_WIDTH (1200).

  • height (int | None, optional) – Figure height in pixels. Default is None, which gives PLOT_HEIGHT (700) for one subplot and SUBPLOT_HEIGHT (350) per subplot otherwise.

  • vertical_spacing (float, optional) – Gap between subplots as a fraction of the figure height (0 to 1). Default is SUBPLOT_VERTICAL_SPACING (0.12).

Returns:

Plotly figure. Change anything not exposed here (fonts, colors, margins, axis ranges, …) with fig.update_layout, fig.update_xaxes, fig.update_yaxes or fig.update_traces before calling fig.show(). Target one subplot with row=i, col=1, and its right axis with secondary_y=True, e.g. fig.update_yaxes(type="log", row=2, col=1, secondary_y=True).

Return type:

go.Figure

Examples

>>> from perda.plotting import plot_time_series
>>> fig = plot_time_series(
...     rows=[[speed_di], [roll_di, pitch_di]],
...     right_rows=[[], [steering_di]],
...     y_axis_titles=["Speed (m/s)", "Attitude (deg)"],
...     right_y_axis_titles=[None, "Steering (deg)"],
...     timestamp_unit=aly.data.timestamp_unit,
... )
